# Architecture & System Design — AI Career Twin

## 1. High-Level Concept
The Career Twin model represents a candidate's skills, commit patterns, learning speed, and market trajectory as an interconnected computational model.

## 2. 3-Layer Architecture
- **Data Ingestion**: Multi-source ingestion from resume text, GitHub usernames, and uploaded technical certificates.
- **Intelligence Core**: FastAPI service orchestration coordinating Gemini 1.5 Flash, scikit-learn regressors and classifiers, knowledge graphs, and RAG resource indices.
- **Presentation**: Single-page dashboard interface running on modern semantic HTML, CSS custom properties, and vanilla JS web APIs.
